> 复制本文件填充内容。每题四要素（题干 / 考查点 / 出处 / 参考答案 / 易错提示）不可省略。答案与解析集中放第五节，方便拆分发放。

```
材料：[粘贴教学材料要点，或注明来源]
学段 / 学科：[未指定时写「按材料推断，待确认」]
题量：[基础 X / 进阶 Y / 挑战 Z]

## 一、知识点清单（含出处）
| 编号 | 知识点 | 出处 |
|---|---|---|
| K1 | [概念/公式/结论] | 材料第 X 段 |
| K2 | ... | 材料第 X 段 |

## 二、基础层
### 题 1
- 题干：[题目]
- 考查点：[识记/直接应用：对应 K?]
- 出处：材料第 X 段
- 参考答案：[答案]
- 易错提示：[学生可能怎么错]

（进阶、挑战层同此结构）

## 三、进阶层

- 题干：[题目]

- 出处：材料第 X 段
- 参考答案：[答案]
- 易错提示：[学生可能怎么错]

## 四、挑战层

## 六、超纲提示
- [若有] 题 X 用到材料外知识「XXX」→ 标「需补充前置知识」或已改写为材料内问法

```

## 填写约束

1. 每题五要素（含易错提示）缺一不可，少一项退回重补。
2. 「出处」必须能回溯到第一节知识点清单的编号或段落。
3. 选择题干扰项须合理（见 `references/distractor-rules.md`），不得一眼假。
4. 答案与解析必须独立成节，不与题面混排。
5. 用到材料外知识的题目必须进第六节，标注处置方式。
