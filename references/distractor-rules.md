# 干扰项设计规则

适用于选择题。干扰项的目标是「能反映真实错误」，而不是「凑够四个选项」。一眼假的干扰项会降低题目区分度，等于没出。

## 设计原则

1. **每个干扰项都要对应一类典型错误** — 学生为什么选它？必须有真实的心理依据，不能是随机凑数。
2. **数值干扰要用「常见算错的结果」** — 比如移项没变号、漏乘分母、单位换算错。不要出现明显离谱的数。
3. **概念干扰要用「相邻易混概念」** — 把材料里极易混淆的术语 / 公式放进去，而不是毫不相干的东西。
4. **正确项不能因表述特殊而被排除** — 正确项在长度、句式、风格上应与干扰项一致，避免「最长的是答案」这类可钻空子。
5. **数量默认 3 个干扰项（共 4 选 1）**；若材料知识点太少放不满 3 个合理干扰项，宁可少出选择题或改用填空 / 简答。

## 反例（不要这样出）

- 题干问「2+3=?」，干扰项给 9、100、-50 — 一眼假，无区分度。
- 概念题把正确项写得明显更长更完整，其余三项残缺 — 学生靠句式就能蒙对。

## 正例

- 计算题：正确 5，干扰项 6（漏看负号）、4（少加一项）、8（把乘当加）— 每个都对应一个真实错法。
- 概念题：正确「密度是质量与体积之比」，干扰项「密度是体积与质量之比」（颠倒）、「密度随质量增大而增大」（忽略定义）、「密度大的物体一定更重」（混淆密度与重量）。

## 自检

- 每个干扰项能否说清「学生会在什么情况下选它」？说不清 → 重写或删除。
- 正确项是否和干扰项风格一致？不一致 → 调整。
- 有没有一眼假的极端值？有 → 替换为合理错法值。
