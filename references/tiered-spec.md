# 三层出题规格

三层的核心区别是「认知深度」与「是否需要材料外知识」。判断标准唯一：是否用到材料之外的内容。

## 基础层（识记与直接应用）

目标：学生读完材料就能做，不需要推导，只需回忆或直接套用。

动词表（题干优先用这些）：
- 复述 / 写出 / 列举 / 指出 / 命名 / 填空 / 判断正误 / 选择（概念辨析）/ 计算（直接代入）

样例题型：
- 填空：材料第 X 段给出的定义是「______」。
- 选择：下列选项中，属于材料所述「XX」的是（直接考概念）。
- 简答：用自己的话写出材料中「XX」的含义。
- 计算：把材料给出的公式直接代入已知数求值（数据来自材料）。

占比建议：默认 3 题。

## 进阶层（变形或组合两个知识点）

目标：需要把材料里的一个知识点做变形，或把两个知识点组合起来，但仍可用材料内知识解决。

动词表：
- 比较 / 分类 / 说明原因 / 改错 / 换情境应用 / 组合 / 推导（一步）/ 解释（为什么）

样例题型：
- 比较：材料中的 A 与 B 有什么相同点与不同点（两个知识点组合）。
- 换情境：把材料例题的情境换成「XX」，结论是否还成立？为什么？
- 改错：下面这句话哪里错了，写出正确表述（错点在材料易混点里）。
- 一步推导：根据材料给的两个条件，推出一个材料没明说但能推出的结论。

占比建议：默认 3 题。

## 挑战层（推理综合或迁移）

目标：需要综合多个知识点，或迁移到材料没直接说、但用材料内知识能推到的场景。仍不得超纲。

动词表：
- 综合 / 论证 / 设计（小方案）/ 迁移应用 / 推理（多步）/ 评价（依据材料标准）

样例题型：
- 综合：用材料第 2、4 段的知识点，解释「XX 现象」为什么会发生。
- 迁移：若把材料的方法用到「类似但没提到的场景 Y」，需要注意什么（只用材料原理，不引入新材料）。
- 设计：根据材料给的原则，设计一个满足条件的小例子 / 小方案。
- 评价：依据材料的标准，判断某做法是否合理并给出依据。

占比建议：默认 2 题。

## 分层自检清单

- 基础层是否只考回忆与直接应用？是 → 通过；否 → 降级或改写。
- 进阶层是否至少组合 / 变形了两个点？是 → 通过；仍是单一识记 → 升为基础或加变形。
- 挑战层是否综合或多步推理？是 → 通过；只是复杂一点的进阶 → 改写。
- 三层是否都只用材料内知识？任一层用到材料外 → 标「需补充前置知识」或改写。
